## 🎯 Функциональность

### Что делает система:
1. **Запускает два поиска для каждой страны:**
   - Из Варшавы (основной фильтр)
   - Из всех аэропортов (без привязки к конкретному аэропорту)

2. **Сравнивает результаты и находит:**
   - Отели до 8000 PLN, которые есть в любых аэропортах, но отсутствуют в Варшаве
   - Отели, которые дешевле из других аэропортов, чем из Варшавы

3. **Создает отчеты:**
   - JSON файлы с детальными результатами сравнения
   - Текстовые отчеты для чтения
   - Обновленные дашборды с новой информацией

### Новые поля в данных:
- `departure_airport` - Аэропорт вылета (Warszawa, Kraków, Gdańsk, и т.д.)

## 🚀 Использование

### Запуск мониторинга всех стран с сравнением:
```bash
python3 run_all_countries_with_airport_comparison.py
```

### Запуск мониторинга одной страны:
```bash
python3 travel_monitor_with_airport_comparison.py --base-config config.json --any-airports-config config_any_airports.json
```

### Генерация дашбордов:
```bash
python3 generate_all_dashboards_with_airport_comparison.py
```

### Тестирование:
```bash
python3 test_airport_comparison.py
```

## 🎨 Дашборд

### Новые возможности дашборда:
1. **Секция сравнения аэропортов** с ключевыми метриками
2. **Новые колонки в таблице отелей:**
   - Аэропорт вылета
   - Лучшее предложение (если есть дешевле из других аэропортов)
3. **Визуальные индикаторы экономии** при вылете из других городов
4. **Информация об отелях**, отсутствующих в Варшаве

### Примеры отображения:
- 🏨 **Отели до 8000 PLN, отсутствующие в Варшаве** - отдельная секция
- 💰 **Экономия при вылете из других аэропортов** - в таблице отелей
- 📊 **Статистика сравнения** - в верхней части дашборда

## 🔧 Технические детали

### URL для поиска из всех аэропортов:
```
https://fly.pl/kierunek/grecja/?filter[dest]=14:&filter[from]=&filter[person]=2...
```
(Параметр `filter[from]=` пустой)

### Лимиты цен:
- Варшава: 8100 PLN
- Все аэропорты: 30000 PLN (для поиска большего количества вариантов)

### Формат данных:
- CSV файлы с новым полем `departure_airport`
- JSON файлы с результатами сравнения
- Текстовые отчеты для чтения
